## 1. What this is

A 17-page marketing site whose job is to make a high-value purchase feel verifiable:
present the portfolio, prove delivery, and route every visitor into a sales
conversation (WhatsApp, call, site visit, or form). There are two audiences:
buyers in Addis Ababa, and diaspora buyers who cannot visit before they commit.

**Stack:** hand-written static HTML/CSS/JS, generated by a dependency-free Node build.
There is no framework, no CMS, no backend, and no third-party runtime scripts.
Fonts are self-hosted. The only external embeds are Google Maps (Urban Kaza) and
OpenStreetMap/Leaflet (Contact, vendored locally).

## 3. Local setup

Requirements: Node 20+, and Microsoft Edge for the test harness (it drives headless Edge
over CDP). Python 3 and Blender 5.2 are only needed to regenerate renders.

```bash
npm install
npm run build     # regenerate the HTML
npm run serve     # http://localhost:8422
npm run check     # expects 139 passes, 0 failures, 0 console errors
```

The HTML in the repository root is the finished site. Any static host can serve it
as-is; `_build/` and the underscore folders are tooling and are excluded from deploys
by `.vercelignore`.

## 4. How to change things

| To change… | Edit | Then |
|---|---|---|
| Any copy, project fact, unit, floor, contact, testimonial | `_build/data.mjs` | `npm run build` |
| Page structure | `_build/pages/*.mjs`, shared parts in `_build/ui.mjs` | `npm run build` |
| Styling | Add to `assets/css/refine-2026.css` (loaded last) | No build needed |
| Behaviour | `assets/js/hb.js` | No build needed |
| Add a render | Put a WebP at `assets/img/<name>-1400.webp` (+ `-800`), add it to `_build/images.json` | `npm run build` (the build fails if a referenced image is missing) |
| Blog article | `_build/blog.json` | `npm run build` |

Never hand-edit the generated `.html` files; the next build overwrites them.

## 5. Systems worth knowing about

### 5.1 Brand intros (Home and Urban Kaza)
The intros are CSS/SVG animations, not video (`_build/intros.mjs` and section 2–3 of
`refine-2026.css`). They play once per browser session (`sessionStorage` keys
`hb-intro-v3` and `uk-intro-v4`). An inline script in `<head>` sets the "seen" class
before first paint, so returning visitors never see a flash. The intros can be skipped
(click / Esc / Enter, or the Urban Kaza "Skip intro" button) and are disabled when the
visitor has reduced motion enabled. When the intro panel starts to dissolve, the page
arrives: the hero comes into focus and the header and headline rise into place
(`.intro-lock` → `.intro-reveal`, section 6 of the CSS).

### 5.2 Urban Kaza zoning model ("Every floor has a function")
There are 18 orthographic white-clay renders: 3 views (aerial, low angle, elevation) ×
6 states (no highlight + 5 zones, each lit in terracotta). They are generated by
`_build/kaza3d/model.py` in Blender. The script also writes `out/anchors.json`, which
holds the projected screen position of each zone label. The page template reads that
file, so the labels stay aligned if the model or camera changes.

```bash
blender -b -P _build/kaza3d/model.py -- all all 96 2400 1500   # about 5 min on an RTX 4060
node _build/kaza3d/webp.mjs                                       # → assets/img/zoning/
npm run build
```

The massing was traced from the client's renders and the end elevation was measured
from the supplied image. **It is a presentation model, not survey geometry.** If the
architect supplies the IFC or DWG, rebuild it from those.

### 5.3 "Kaza Living" → "Urban Kaza"
The project was renamed after most of the renders were produced. The client supplied
four corrected renders; the remaining lettering (other renders and the showcase video)
was re-signed with the official lockup glyphs. Stills were handled by
`_build/kaza-fix/*.py`; the video by planar tracking in `_build/vfix/track.py`. Any new
render from the visualiser must say **URBAN KAZA**.

### 5.4 Interior viewer (Recreation Centre)
This is a zone-tabbed stage plus a filmstrip (`[data-zones]` in `hb.js`). Full-screen
view reuses the site lightbox through `window.hbLightbox(list, index)`. Without
JavaScript, every zone and thumbnail is still listed and linked.

## 6. Must be done before public launch

1. **Wire the inquiry form.** Every form validates but sends nothing yet. Set
   `window.HB_FORM_ENDPOINT` to a POST endpoint that accepts `FormData` and returns 2xx
   (for example Formspree, a serverless function, or the CRM's web-to-lead URL). Campaign
   attribution (UTM fields and the landing page) is appended automatically; see
   `submitInquiry()` in `hb.js`. Until the endpoint is set, the form tells the visitor
   honestly that it is not connected and keeps what they typed.
2. **Custom domain.** Point `hillbottomproperties.com` at the Vercel project
   (Project → Settings → Domains) and retire the WordPress site. Add 301 redirects for
   old WordPress URLs that have search traffic.
3. **Analytics / consent.** None is installed. Add the client's choice (GA4, Plausible,
   or Vercel Analytics) and a consent banner if required.
4. **SEO basics.** Add a `sitemap.xml`, a `robots.txt`, canonical tags and `og:image`
   once the final domain is known. Titles and descriptions already exist on every page.

## 10. Known gotchas

- **Replacing an image or video: give it a new filename** (e.g. `-v3`) and update the
  reference; never overwrite a file under the same name. Browsers keep media for up to
  a week (`vercel.json`), so a same-name swap stays invisible to returning visitors.
  `_build/version-assets.py` shows how the September re-renders were versioned.
- Vercel is configured to skip install/build (`vercel.json`): the HTML is prebuilt
  locally and committed. Always run `npm run build` before deploying.
- Do **not** enable `cleanUrls` on Vercel (internal links use `.html`).
- Deploy with `--archive=tgz`; plain uploads fail on this project.
- The local server (`npm run serve`) must be running for `npm run check`. If it is
  down, the harness captures a 404 page without complaining.
- Changing the zoning model requires re-rendering **and** rebuilding, because label
  positions come from `anchors.json`.
- `_build/images.mjs` points at the render source folder used during the original
  build. Change `SRC` before re-running it on another machine.
